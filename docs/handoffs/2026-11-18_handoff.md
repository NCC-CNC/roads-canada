## Summary

Found the paper's land mask and validated the OSM roadless-area prototype on
all five Table 4 provinces. The Statistics Canada 2016 Cartographic Boundary
File reproduces the paper's land areas exactly, and with it roadless area is
within 0.5% of Table 4 everywhere and patch counts within about 5%. A
synthetic test and CI test job are open in a PR. Two PRs are still waiting
for review.

## Completed

- Settled with the user: patch metrics are secondary; try the local StatCan
  boundary from the Poley compilation before downloading anything. The paper
  and supplement name no boundary file, so the identification rests on the
  land-area match.
- PR #18 (merged): design note 06 and a data sources entry. The user
  downloaded the file from StatCan and it is byte-identical to the compilation
  copy. Licence: only the 2016 reference guide mentions the Statistics Canada
  Open Licence Agreement; no licence on the website or in the download.
- Corrected an error of mine mid-session: `lpr_000a16a_e` is the Digital file
  (extends into water, 76,209 km2 for Nova Scotia) and `lpr_000b16a_e` is the
  Cartographic file (57,534 km2, matches the paper). Use the cartographic file.
- Sub-agent ran BC, AB, ON and QC and opened PR #19 (results, note 07) and
  PR #20 (pytest synthetic test and CI `test` job). Both pass CI; neither is
  merged.
